# 엔터프라이즈 SSD
데이터 센터에서 랙 스토리지 또는 애플리케이션 서버로 사용하도록 설계되었습니다. 클라이언트 SSD와 달리 엔터프라이즈 SSD는 하나 이상의 마더보드 PC에서 쓰기 및 읽기 명령을 받을 수 있습니다. 랙 스토리지에 설치된 SSD는 일반적으로 RAID 스토리지로 사용되도록 구성되며, 여러 드라이브가 단일 장치로 작동하여 성능 또는 데이터 중복성을 향상시킵니다.
