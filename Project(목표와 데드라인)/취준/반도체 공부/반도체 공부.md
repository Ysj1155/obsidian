# 반도체 공부 허브

## 이 허브의 역할

반도체 제조 공정, 기본 용어, 테스트 직무, SSD 제품·controller 지식을 한 지도에서 연결한다. 각 branch는 서로 다른 층위를 담당하며, 특정 층의 관찰만으로 다른 층의 원인을 단정하지 않는다.

- 상위 허브: [[취준]]

## 분야별 입구

- [[9대 공정|반도체 9대 공정 허브]]
  - 웨이퍼부터 EDS와 패키징까지 제조 흐름을 읽는다.
- [[반도체 용어|반도체 용어 허브]]
  - NAND/NOR, IC, XIP 등 반복 용어를 정리한다.
- [[테스트 엔지니어]]
  - ATE resource, analog test, EDS·후공정 test와 직무 관점을 모은다.
- [[SSD 허브]]
  - SSD 구조, 성능, FTL/GC, 실제 장치와 simulator 검증을 연결한다.

## 층위 지도

```text
반도체 소자와 재료
  -> 웨이퍼 제조·전공정
  -> EDS·패키징·후공정 테스트
  -> NAND package와 SSD controller
  -> firmware / protocol / host path
  -> 제품·시스템 validation
```

## 구분해서 말할 것

- 제조 공정 defect와 controller firmware defect
- Wafer-level test, package test, SSD system-level validation
- NAND media 물리 현상과 FTL 정책
- 실제 SSD black-box evidence와 Python simulator의 white-box model
- Vendor 문서의 claim과 내가 재현한 결과
