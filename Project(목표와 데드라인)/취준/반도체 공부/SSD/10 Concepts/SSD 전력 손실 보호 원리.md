## 1. 비정상적 정전의 숨겨진 위험

합리적인 전원 차단 보호 메커니즘이 없고 비정상적인 전원 차단이 불가피한 경우, 비정상적인 전원 차단이 발생하면 많은 문제가 발생하게 됩니다.

### 1.1 디스크 분실

비정상적인 정전으로 인해 매핑 테이블이 너무 늦게 저장되고 논리적 주소와 물리적 주소 간의 매핑이 손실됩니다. 전원을 다시 켜면 BIOS가 SSD를 인식하지 못합니다. 문제는 수리를 위해 공장에 반품해야만 해결될 수 있습니다. 그러나 소위 공장으로 돌아가는 것은 카드를 다시 열어 잃어버린 디스크 문제를 해결하는 것입니다. 카드를 다시 열면 모든 사용자 데이터가 손실됩니다!

### 1.2 캐시의 데이터 손실

일반적으로 SDRAM 또는 DDR을 캐시로 사용합니다. 여기서 SDRAM은 비휘발성 저장 매체이며 정전 후 데이터가 손실됩니다.

### 1.3 불량 블록 증가로 인한 잘못된 판단

MLC에서는 2비트의 데이터를 저장할 수 있으며, 페이지는 공유 페이지 형태로 저장된다. LSB와 MSB의 물리적 셀의 두 비트는 각각 두 개의 서로 다른 페이지에 매핑됩니다. LSB(하위 유효 비트)는 하위 페이지에 배치됩니다. MSB(최상위 비트)를 페이지 상단에 넣어 저장합니다. 작동 규칙은 LSB를 먼저 작동시킨 다음 MSB를 작동시키는 것입니다. 따라서 느린 페이지의 작업은 빠른 페이지의 작업보다 시간이 덜 걸립니다.

## 2. SSD 전원 손실 보호의 원리

일반적으로 SSD는 정전 후 탄탈륨 커패시터 또는 슈퍼 커패시터를 전원 공급 장치로 사용합니다. 탄탈륨 커패시터는 넓은 온도 환경에 적합하지만 용량이 작습니다. 슈퍼커패시터는 고온, 저온 환경에는 적합하지 않지만 용량이 크다.

- 슈퍼 커패시터(또는 탄탈륨 커패시터)는 일반 전원 공급 장치를 통해 충전됩니다.
- 슈퍼 커패시터(또는 탄탈륨 커패시터)의 입력 끝과 SATA 전원 공급 장치의 입력 끝에서 입력 전원 공급 장치가 각각 감지되고 감지 회로가 해당 GPIO 포트에 연결됩니다.
- 전원 공급 장치가 갑자기 차단되는 순간 GPIO를 통해 펌웨어로 피드백됩니다.
- 포트 5V의 연결이 끊어지면 펌웨어는 HOST로 피드백되고 SSD로 전송되지 않은 데이터를 더 이상 수신하지 않습니다.
- 리미트 회로단의 검출 회로는 HOST로 피드백됩니다. 전원 입력이 전환되고 전원 공급 장치가 슈퍼 커패시터(또는 탄탈륨 커패시터)로 전달되어 정전 후 매핑 테이블과 캐시에 데이터를 쓰는 데 필요한 전력을 업데이트합니다.
