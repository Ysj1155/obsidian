# 재현되지 않은 가설도 검증 결과다

## 한 줄 결론

- SSD validation에서 실험이 `Pass`라는 말은 “성능 가설이 맞았다”는 뜻이 아닐 수 있다.
- 요구한 evidence가 완성되면 requirement는 Pass일 수 있지만, 성능 방향이 반복되지 않으면 performance hypothesis는 `not reproduced`로 분리해야 한다.

## 왜 이 노트가 필요한가

- 벤치마크 관점에서는 원하는 성능 방향이 안 나오면 실패처럼 보일 수 있다.
- 검증 관점에서는 가설이 재현되지 않았다는 사실도 중요한 evidence다.
- 특히 black-box SSD 실험에서는 session state, USB, Windows, exFAT, file target, host activity 같은 통제 밖 요인이 크기 때문에, 단일 run에서 그럴듯한 방향을 잡아도 반복성으로 방어하지 못하면 결론을 낮춰야 한다.

## 관찰한 사례

### Mixed ABBA / BAAB

| Session | Comparison | Read BW | Read p99 | Read p99.9 |
|---|---|---:|---:|---:|
| ABBA | B2/B1 | 0.712x | 1.345x | 3.925x |
| BAAB | B2/B1 | 1.224x | 0.910x | 0.724x |

- ABBA에서는 두 번째 mixed phase가 느려지고 tail도 나빠졌다.
- BAAB에서는 방향이 반대로 나왔다.
- 따라서 repeatable 70:30 read-tail inflation 가설은 재현되지 않았다.

### Mixed Ratio Cross-Session

| Comparison | Session 1 | Session 2 | Reproduced |
|---|---|---|---|
| Total-BW ratio rank | 70:30 > 90:10 > 50:50 | 90:10 > 70:30 > 50:50 | No |
| Cycle BW rank | 3 > 2 > 1 | 1 > 3 > 2 | No |
| Position BW rank | 1 > 2 > 3 | 3 > 2 > 1 | No |
| Phase 5 last/first BW | 0.524x drop | 1.384x rise | No |
| 30-60s ramp phases | 0 / 9 | 8 / 9 | No |

- ratio, cycle, position, phase-transition 방향이 independent session에서 재현되지 않았다.
- 가장 강한 결론은 특정 ratio 효과가 아니라 session-level black-box state variation이었다.

### Idle Ramp

| Requested idle | Ramp count | Pair classification | Repeat 2 / 1 BW |
|---:|---:|---|---:|
| 0s | 0 / 2 | Consistent: no ramp | 1.149x |
| 60s | 0 / 2 | Consistent: no ramp | 0.996x |
| 300s | 0 / 2 | Consistent: no ramp | 1.558x |

- prior 37-53초 ramp는 어떤 idle duration에서도 재현되지 않았다.
- pre-probe idle length는 ramp presence, transition time, overall performance state의 안정적인 설명이 아니었다.
- 300초 idle pair는 ramp classification은 같았지만 bandwidth는 55.8% 달랐다.

## 해석 기준

- Requirement Pass:
  - 계획한 phase가 모두 실행됐다.
  - raw JSON, manifest, CSV, observer evidence가 연결됐다.
  - 분석이 재현 가능한 형태로 남았다.
- Performance hypothesis not reproduced:
  - 방향이 독립 session에서 유지되지 않았다.
  - ratio, cycle, position 같은 후보 설명이 서로 충돌했다.
  - black-box state variation이 더 방어 가능한 결론이다.

## 좋은 검증 언어

| 피해야 할 말 | 더 좋은 표현 |
|---|---|
| SSD가 느려졌다 | 이 조건에서 fio-observed bandwidth 또는 tail latency가 변했다 |
| 캐시 때문이다 | cache, filesystem, host path effect 가능성이 있지만 식별하지 못했다 |
| 실험 실패다 | performance hypothesis는 재현되지 않았지만 evidence requirement는 충족했다 |
| 70:30이 read tail을 망친다 | 이 DUT/path/session에서는 70:30 read-tail inflation이 반복 재현되지 않았다 |

## 포트폴리오 / 면접 포인트

> mixed workload와 idle-ramp 실험에서 원하는 성능 가설이 반복되지 않았을 때, 이를 실패로 버리지 않고 requirement verdict와 performance hypothesis verdict를 분리했습니다. 모든 phase, raw JSON, manifest, CSV evidence는 Pass로 남기되, 방향이 독립 세션에서 재현되지 않은 가설은 `not reproduced`로 낮춰 해석했습니다. 이 과정에서 black-box SSD 검증에서는 결과보다 해석 경계와 반복성이 더 중요하다는 점을 배웠습니다.
