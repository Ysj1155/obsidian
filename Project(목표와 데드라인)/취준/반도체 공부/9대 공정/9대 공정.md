# 반도체 9대 공정 허브

## 이 허브의 역할

삼성전자 반도체 공식 콘텐츠를 중심으로 수집한 공정 자료를 제조 흐름 순서로 연결한다. 이 폴더의 긴 문서는 대부분 원문 스크랩이므로, 공정의 전체 위치를 잡고 필요한 원문으로 이동하는 입구로 사용한다.

- 상위 허브: [[반도체 공부]]
- 관련 직무 허브: [[테스트 엔지니어]]
- SSD와의 연결: NAND가 만들어지는 제조 배경과 EDS/패키징 이후 제품 검증의 위치를 이해한다.

## 공정 흐름

```text
웨이퍼
  -> 산화
  -> 포토
  -> 식각
  -> 증착·이온주입
  -> 금속 배선
  -> EDS
  -> 패키징
  -> 제품/시스템 수준 테스트
```

## SSD Validation 관점에서 볼 질문

- NAND cell과 interconnect가 어떤 제조 흐름을 거쳐 만들어지는가?
- Wafer-level EDS, package test, SSD system-level validation은 무엇을 각각 검출하는가?
- 공정 variation과 package/thermal condition이 제품 동작과 신뢰성에 어떤 배경 변수가 되는가?
- 제조 불량, NAND media failure, controller firmware defect, host-path 문제를 어떻게 다른 층위로 구분하는가?

## 읽을 때 주의할 점

- 원문 스크랩의 설명을 그대로 내 결론으로 사용하지 않는다.
- 공정 소개 자료의 쉬운 설명과 실제 공정 조건·장비 recipe를 구분한다.
- SSD black-box 결과만으로 특정 제조 공정 원인을 단정하지 않는다.
- 각 원문의 오래된 `obsidian://` 링크는 현재 vault 경로와 다를 수 있다.
