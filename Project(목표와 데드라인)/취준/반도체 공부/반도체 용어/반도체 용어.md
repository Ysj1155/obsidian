# 반도체 용어 허브

## 이 허브의 역할

반도체 공부에서 반복해서 만나는 소자·메모리·실행 구조 용어를 모은다. 원문을 복사한 자료는 출처 노트로 유지하고, 공부가 끝난 개념은 한 줄 정의와 비교 기준이 있는 개념 노트로 성장시킨다.

## 앞으로 분리할 축

- 소자: transistor, diode, capacitor
- Memory: SRAM, DRAM, NAND, NOR
- 구조: die, plane, block, page, cell
- 신뢰성: retention, endurance, read disturb, program disturb
- 제품: controller, package, interface, protocol

## 정리 기준

- 비슷한 용어는 차이를 표로 남긴다.
- 제조 공정, device physics, controller firmware, host software의 층위를 표시한다.
- Vendor 설명은 일반 원리와 제품 claim을 분리한다.
- SSD 내부 원인과 black-box에서 관찰한 증상을 같은 사실로 취급하지 않는다.
