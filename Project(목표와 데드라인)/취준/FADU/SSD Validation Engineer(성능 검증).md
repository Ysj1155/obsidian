SSD는 시장과 ​고객의 ​요구 ​사항을 충족함과 ​동시에, PCIe, NVMe 등 ​업계 ​표준을 준수하고 ​다양한 인증을 획득해야 ​하는 고신뢰성 ​제품입니다. ​FADU Validation ​팀은 ​SSD가 ​이러한 조건을 만족하며 ​설계 ​의도대로 안정적으로 동작하는 ​지를 ​종합적으로 ​검증하는 역할을 수행합니다.

**담당 ​업무**
- SSD 제품의 성능 ​및 ​파워 검증
- SSD 제품의 성능 ​및 파워 ​테스트 ​케이스 설계 및 ​개발
- 테스트 결과 ​분석 및 디버깅을 통한 문제 원인 파악, 개선안 도출
- Python 및 Shell Script 기반의 테스트 자동화
- Enterprise향 SSD 고객 요구사항 분석 및 반영

**자격 요건**
- 전자, 반도체, 정보통신, 컴퓨터 관련 학사 이상
- Storage 기술에 대한 기초 지식 및 실험 기반 사고력
- Python 및 Shell Script 프로그래밍 가능
- 논리적 분석력 및 문제 해결 능력 보유


**우대 사항**

- NAND Flash 기반 Storage(SSD/eMMC) 관련 개발/검증 경험 (FIO Tool을 활용한 SSD성능, 파워 검증 경험)
- Storage Benchmark Tool 사용 및 분석 경험 (DLIO, MLPerf, ACT 등)
