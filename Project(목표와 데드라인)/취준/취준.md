# 취준 허브

## 이 허브의 역할

SSD Validation과 반도체 테스트 직무 준비를 위한 최상위 입구다. 기술 학습, 프로젝트 evidence, 회사 자료, 면접 준비, 원본 스터디 기록을 서로 다른 branch로 유지하면서 필요한 지점에서 연결한다.

## 먼저 들어갈 곳

1. [[SSD 허브]]: SSD 구조, black-box Mini Lab, white-box FTL-GC Lab
2. [[반도체 공부]]: 공정, 반도체 용어, 테스트 엔지니어 지식
3. [[FADU]]: 회사·제품·직무 자료와 vendor source
4. [[면접 대비]]: 프로젝트를 답변으로 바꾸는 공간
5. [[취업 스터디 허브]]: 날짜별 취준 조언과 당시 판단의 원본

## 현재 핵심 프로젝트

- [[SSD Mini Lab 프로젝트 허브]]
  - 실제 외장 SSD를 fio로 측정하고 평균, tail latency, 반복성, telemetry를 분석한다.
- [[SSD FTL-GC White-box Validation Lab]]
  - FTL/GC의 상태 전이, resource contention, fault와 recovery를 deterministic simulator로 검증한다.
- [[00 SSD Controller and Verification 학습 지도]]
  - FSM, handshake, FIFO, bus, DMA, arbitration, assertion을 SSD controller 관점으로 학습한다.

## 준비 흐름

```text
직무 요구 파악
  -> 필요한 개념 학습
  -> 프로젝트에서 직접 검증
  -> 결과와 한계 기록
  -> 면접·자소서 문장으로 변환
  -> 지원 회사에 맞춰 evidence 선택
```

## 운영 원칙

- 외부 자료는 source/reference로 남기고 내 결론과 분리한다.
- 프로젝트 수보다 검증 질문, 조건, 결과, 한계를 설명하는 능력을 우선한다.
- 회사·채용시장 정보는 지원 시점에 최신 공식 자료로 다시 확인한다.
- Inbox와 스터디 기록은 생각의 원본으로 보존하고, 소화된 내용만 허브와 개념 노트로 승격한다.
